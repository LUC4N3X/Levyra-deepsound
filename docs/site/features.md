# Features

Levyra combines native playback, discovery, offline ownership and local-first listening tools in one music experience.

## Playback

- Media3 / ExoPlayer playback on Android.
- Dedicated libvlc playback core on Windows.
- Queue management, shuffle and repeat.
- Gapless playback.
- Volume normalization.
- Speed and pitch controls.
- Sleep timer.
- Android Auto and external media controls.
- Audio and native-video modes.

## Discovery

- Your Orbit.
- Quick Picks.
- Global charts and editorial collections.
- Personalized radio.
- Similar songs.
- Rediscovery of older favorites.
- Artist, album and playlist exploration.
- Samples and video-driven discovery surfaces where supported.

## Lyrics & visuals

- Synced lyrics.
- Tap-to-seek lyric navigation.
- Lyric sharing.
- Artwork preview.
- Canvas and motion artwork.
- Levyra Ambient for a low-distraction OLED-friendly now-playing experience.

!!! note
    Visual enrichment is intentionally secondary to audible playback. Artwork, Canvas or motion features should never be required for music to start.

## Offline ownership

Supported downloads can be saved as tagged M4A files with metadata such as:

- title;
- artist;
- album;
- artwork;
- lyrics.

Local files remain usable with compatible players outside Levyra.

## Library

- Favorites.
- Playlists.
- Playlist tags and filtering.
- Hidden playlists.
- Followed artists.
- Artist exclusions from recommendations.
- Local listening history and insights.
- Backup and restore through Levyra Vault.

## Recognition & integrations

- Music recognition from microphone input.
- Supported internal-playback capture on compatible Android versions.
- Optional recognition provider fallback.
- Last.fm and ListenBrainz scrobbling.
- SponsorBlock integration.
- Network controls including supported DNS and proxy options.

## Privacy

Core use does not require:

- a Levyra account;
- an advertising profile;
- mandatory analytics;
- mandatory cloud sync.

See [Privacy & Data](privacy.md) for the technical overview.
